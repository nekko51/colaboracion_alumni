\section{Support Vector Machine}

We intend to back up the humanness of the chain outputted by the simulated annealing algorithm with this binary-output method.

The main point of an SVM (abbreviation of Support Vector Machine) is to transform our data space into some other one in such a way that we can separate the data points with a simple hyperplane, a linear classifier.

We will represent each point with a $n$-dimensional vector, where $n$ is the number of data points. The function that gives us those coordinates is called the kernel.

\subsection{The kernel}

Our kernel, $\operatorname k:\mathcal C\times\mathcal C\to \mathbb R$, will be the Gaussian radial basis function: $$\operatorname k(\textbf x_i, \textbf x_j)=\exp \left( 
    -\gamma \left\| \textbf x_i -\textbf x_j \right\|^2 
\right),\ \gamma>0,$$ where $\{\textbf x_i\}$ are the data points.

After applying the kernel we have a matrix $M\in\mathbb R^{n\times n}$, the Gram matrix, with the coordinates of our data points in the new space. That will be: $[M]_{i,j}=\operatorname k(\textbf{x}_i,\textbf{x}_j)$.

We also have available four other standard kernel functions:\futnotetext\footnotetext{These constants ($298$ and $596=2\cdot 298$) that are scattered around the functions seem to be arbitrary, but the written functions are already optimized for our use case: they are normalized and centered so that every output is positive and does not surpass 1.}

\begin{multicols}{2}
\begin{itemize}
    \item Sigmoid function:
    \begin{equation*}
        \operatorname k(\textbf{x} _i,\textbf{x} _j)=\tanh \frac{
            \left\langle \textbf{x} _i| \textbf{x} _j \right\rangle
        }{
            298
        }
    \end{equation*}

    \item Tanimoto function:
    \begin{equation*}
        \operatorname k(\textbf{x} _i,\textbf{x} _j)=\frac{
            \left\langle \textbf{x} _i| \textbf{x} _j \right\rangle
        }{596 - \left\langle \textbf{x} _i| \textbf{x} _j \right\rangle}
    \end{equation*}
    
    \item Linear function: \begin{equation*}
        \operatorname k(\textbf{x} _i,\textbf{x} _j)=
        \frac{\left\langle \textbf{x} _i| \textbf{x} _j \right\rangle}{298}
    \end{equation*}

    \item Cauchy function:
    \begin{equation*}
        \operatorname k(\textbf{x} _i,\textbf{x} _j)=\frac{
            298
        }{298 + \left\| \textbf{x}_i-\textbf{x}_j   \right\|^2 }
    \end{equation*}
\end{itemize}
\end{multicols}

The Gram matrix and the kernel are the tools we need in order to craft the decision function.

\subsection{Decision function}

Using the lagrange multipliers method for minimization\futnotetext\footnotetext{\hyperref[sec:svm_formula]{See appendix for full derivation.}}, we get the decision function, $f:\mathcal C\to\mathbb R$:
$$
f(\textbf x) = b + \sum_{i=1}^n\lambda_i s_i \operatorname k(\textbf x_i,\textbf x),
$$
where $\lambda_i$ are the lagrange multipliers obtained through said method, $s_i$ is the \textit{tag} of the $i$-th data point (may be $+1$, when human, or $-1$, when murine) and $b$ is the bias, obtained as follows:
$$
b=s_p-\sum_{i=1}^n \lambda_i s_i \operatorname k(\textbf x_i, \textbf x_p),
$$
where the $p$-th data point is a support one, that is, the closest to the plane (or any of them) and such that $\lambda_p>0$.

\subsection{Custom piecewise kernels}
To address this limitation, we designed a custom piecewise linear kernel function that allows us to concentrate the gradient of the similarity metric in a customizable band of width $W$ centered at $C$:

\begin{figure}[H]
    \centering
    \begin{minipage}[c]{0.6\textwidth}
    \small
    \begin{equation*}
    \operatorname k(\textbf x_i, \textbf x_j) = \begin{cases}
        \dfrac{L}{C - \frac{W}{2}}\, x, & x < C - \dfrac{W}{2} \\[14pt]
        \dfrac{H - L}{W}\!\left(x - C + \dfrac{W}{2}\right)\! + L, & \left|x - C\right| \le \dfrac{W}{2} \\[14pt]
        \dfrac{1 - H}{1 - C - \frac{W}{2}}\!\left(x - C - \dfrac{W}{2}\right)\! + H, & x > C + \dfrac{W}{2}
    \end{cases}
    \end{equation*}
    \vspace{4pt}
    \centering
    \footnotesize where $x = \frac{\langle \textbf x_i \mid \textbf x_j \rangle}{298} \in [0, 1]$, with baseline levels $L = 0.2$ and $H = 0.8$.
    \end{minipage}\hfill
    \begin{minipage}[c]{0.35\textwidth}
    \centering
    \begin{tikzpicture}[scale=1.05, >=Stealth, font=\footnotesize]
        \def\xlen{3.80}

By choosing a narrow width ($W = 0.08$) and positioning the center $C$ in the transition zone ($C \in \{0.78, 0.80, 0.82, 0.84\}$), the ramp acts as a localized magnifier. Sequences far from the boundary are mapped to constant baseline regions, while subtle sequence differences right near the threshold produce sharp changes in the kernel output.

To jointly quantify both discrete classification correctness and continuous margin confidence in a normalized index between 0 and 1, we compute the Quadratic Certainty Score $\mathcal Q$:
\begin{equation}
    \mathcal Q = 1 - \frac{1}{n}\sum_{i=1}^n \left(1 - \frac{1}{1 + e^{-s_i f(\textbf x_i)}}\right)^2 \in [0, 1]
\end{equation}
where $s_i \in \{-1, +1\}$ is the true tag and $f(\textbf x_i)$ is the decision function output. Decisive, correct predictions contribute close to $1.0$, predictions at the decision boundary contribute $0.75$, and confident misclassifications are penalized quadratically down to $0.0$.
